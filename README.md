# 📊 Exportação de Dados

Uma solução automatizada para extração, tratamento e exportação de dados estruturados.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido para simplificar a coleta de dados de fontes externas (APIs, bancos de dados ou arquivos brutos), realizando o devido tratamento, filtragem e conversão para formatos leves e prontos para análise (como CSV, Excel, JSON ou carga em bancos de dados).

### ✨ Funcionalidades
- 📥 **Coleta de Dados:** Leitura e integração com fontes brancas de dados.
- 🧹 **Tratamento e Limpeza:** Normalização de dados, tratamento de valores nulos e formatação.
- 📤 **Exportação:** Geração automatizada de relatórios e arquivos estruturados.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python
- **Bibliotecas:** Pandas, NumPy, OpenPyXL 
- **Ambiente de Desenvolvimento:** VS Code / Jupyter Notebook
